## Hi, I'm Amit Dubey

**Web developer with a fitness-coaching background**, based in Indore, India.

I coach clients in person and online, and I build the tools I wish I'd had as a coach: fast, mobile-first web apps for gyms, trainers and the people they train. Because I work with the users every day, I build software that solves problems I've seen first-hand.

- Building fitness-tech web apps in **JavaScript**
- I care about **clean UI, accessibility and code that's tested**
- **Open to** web developer roles and freelance projects

### How I work

- **Mobile-first:** my users are on their phones in a gym, often with bad signal
- **Logic separate from UI**, so the important rules are covered by unit tests
- **Few dependencies:** small, fast pages that work on budget phones
- **Accessible by default:** semantic HTML, keyboard support, light and dark themes
